# Nova LP Tasty Media

Landing page da Tasty Media (marketing de performance para restaurantes).

Site estático: tudo está em `index.html`, sem build.

## Ver localmente

```sh
open index.html
# ou
python3 -m http.server 8080
```

## Publicar

Pode ser hospedado como está em Cloudflare Pages, GitHub Pages ou qualquer host estático (diretório de saída: raiz do repositório).
